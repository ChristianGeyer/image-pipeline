Title:
Overlapping Bullet Hole Detection Based on Improved Watershed Algorithm

Authors:
Liu, Chen, Kong, Wang, Fu, Wang

Year:
2023

Input:
Grayscale images of ISSF-style paper targets with overlapping bullet holes (“heavy holes”). Images are captured from a target reporting system camera. The paper focuses on local regions containing overlapping bullet holes rather than full-target detection.

Method:
Purely classical image processing. The pipeline is:
1) Preprocessing: grayscale conversion, filtering, and binarization to reduce noise (page 2).
2) Morphological opening and closing to remove small protrusions and holes (page 2).
3) Area-based connected component analysis to remove ring lines, ring values, and background regions by comparing region area to the area of a single bullet hole (page 2).
4) Improved watershed segmentation based on distance transform to split overlapping bullet holes (Fig. 1, page 2).
5) Boundary extraction using 8-neighborhood chain code tracking (page 3, Fig. 2).
6) Least-squares circle fitting on boundary points to estimate circle centers and radii for each bullet hole (page 3).

Dataset:
- 10 real overlapping bullet hole images used for real measurements (page 4).
- 200 synthetic overlapping bullet hole images generated by simulation for validation (page 5).
- Overlap between two bullet holes ranges from 5% to 95% (page 5).
- No full dataset of full targets; only cropped overlapping-hole regions are used.

Evaluation metrics:
- Segmentation quality: Intersection over Union (IoU) and Accuracy (Acc) (page 4).
- Localization accuracy: pixel error between true and estimated bullet hole center coordinates (Table II, page 4).

Accuracy:
Segmentation (Table I, page 4):
Improved watershed vs traditional watershed:
- IoU: 0.931–0.962 vs 0.856–0.904
- Accuracy: 0.915–0.972 vs 0.894–0.921

Localization (Table II, page 4):
- Center-of-mass estimation error for overlapping holes is generally between 0 and 3 pixels.
- Error stays below 3 pixels when overlap ≤ 90.43% (page 5).

Speed:
Not reported. Implementation is in Python 3.9 with OpenCV 4.7 on an Intel i7-7700 CPU (page 5). The method is not optimized for real-time full-target processing.

Key idea:
Overlapping bullet holes are separated using an area-aware watershed segmentation, and each hole’s center is estimated by fitting circles to the extracted boundary using least-squares. This allows multiple bullet holes inside one connected region to be localized geometrically.

Limitations:
- Requires manual tuning of grayscale thresholds and region area thresholds (page 2).
- Only works on cropped regions around bullet holes, not full target images.
- Sensitive to noise, ring lines, and target markings if preprocessing fails.
- Performance degrades when overlap exceeds about 90% (page 5).
- No learning or adaptation; assumes consistent bullet hole size and shape.

Relevance to my thesis:
This paper shows that classical image processing can accurately separate and localize overlapping bullet holes with pixel-level precision, but it depends on strict preprocessing and is not robust to variations in lighting, target appearance, or full-target scenes. It is useful for precise geometric localization but unsuitable as a complete, low-cost real-time ISSF scoring system on its own.
